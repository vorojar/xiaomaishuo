## 关于本书

《小麦说》是一部关于认知、行动、创造、商业、关系与生命修行的思想非虚构作品。它不是语录集，也不是单纯的方法论汇编，而是作者多年思、想与行的阶段性整理。

全书共七卷：

1. 认知与本质篇
2. 拆解与执行篇
3. 变革与创造篇
4. 商业与管理篇
5. 心性与自我篇
6. 情感与社交篇
7. 生死与修行篇
